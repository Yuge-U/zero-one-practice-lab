# ZERO ONE PRACTICE

練習を計画し、実施し、振り返りを次の計画につなぐアプリです。

公開先： https://yuge-u.github.io/zero-one-practice-lab/

## 1.0.0の機能

- 練習名・対象・人数・時間・ゴールから練習項目を組み立て、端末へ保存する。
- 保存済みの練習を「コピーして新規作成」し、時間・メニュー・条件を変えて別の計画として保存する。
- コピーでは元の計画・実績・振り返り・タイマーを変更しない。コピー先に実績・振り返り・タイマーは引き継がない。
- 「この計画を編集」は元の計画の改訂。「コピーして新規作成」とは別操作。
- 練習項目単位の「次の計画に追加」、予定とは別の実績・振り返り、全体タイマー、バックアップ書出しを利用する。
- TERMINOLOGYの用語IDとCANVAS JSONの固定版を保持する。PRACTICE内の「CANVAS 再生」で連続再生・動作単位のコマ送り／コマ戻しを行う。作戦の編集はCANVASで行う。
- 承認された上向き矢印の01アイコン、ZERO ONEの濃色ヘッダー・明るいカード・PRACTICEの緑を使用する。

## 保存の確認

練習名・対象・人数・全体時間・ゴール・各項目の名前と時間を入力し、「端末に保存」を押してください。
未入力や時間超過の理由、保存中、保存完了を保存ボタンの近くに表示します。Variationは空欄なら基本条件になります。
「端末保存」と「クラウド同期」は別です。保存完了の表示を確認し、必要に応じて全体バックアップも保管してください。

## 更新とデータ保管

URLとブラウザ内のSQLiteパス、ゲスト・本人のアカウント境界は変更していません。
URL中の`lab`は互換性のため維持します。名前を変えて別の保存領域へ移す公開ではありません。
更新通知が出たら入力を保存して、このアプリのタブをすべて閉じてから開き直してください。版はヘッダーまたはフッターで確認できます。
**更新のためにSafariのWebサイトデータを削除しないでください。端末内の記録が消える可能性があります。**
端末故障、サイトデータ削除、ブラウザの保存管理に備え、バックアップは端末の保存領域とは別にも保管してください。

## OneDrive・AI・実機確認の範囲

本人所有のOneDrive接続は任意です。Microsoftの既存アプリ登録へのSPA戻り先追加と本人サインインが必要です。
保存先は互換性のため`ZERO_ONE_PRACTICE_LAB_V02`を維持します。作戦や用語学習の既存ファイルを自動移動・削除しません。
ゲストの練習記録はMicrosoft接続後の領域へ自動移行しません。未接続時に記録が運営側へ送られることもありません。
**本人のMicrosoft認証・実OneDrive同期・物理PCとiPhoneの引継ぎは、CIのブラウザ検証とは別の受入項目です。完了した扱いにしません。**
AIはこの版の必須機能ではなく、ChatGPTプロジェクトとの常時自動同期も実装済みとは扱いません。
ユーザーから報告されたiPhoneの保存失敗について、入力時の無言の停止を改善していますが、その実機で起きた原因を確定したものではありません。

## 配信と検証

`production`に今回の差分、入力・コピー試験、実画面試験、版更新試験を置いています。
既存の0.3.2公開ソースを固定コミットから再構成して検査し、許可した差分だけ適用します。公開物は`production/release.json`の全バイト照合を要求します。
`release/practice-1-0`のCIでは公開しません。mainの両OS・両エンジンで合格した成果物だけPagesへ配信します。
公開前には旧版の同じプロファイル・同じURLで計画、振り返り、送信待ちが維持されるかも検証します。
公開後は実HTTPSのファイル照合と、ゲストの合成データによる保存・コピーを再検査します。
CIのWebKitはiPhone Safariそのものではありません。サーバー停止試験は機内モードと同一ではありません。
検証の実測結果は`validation-reports`とGitHub Actionsの成果物を参照してください。

既存のCANVAS・TERMINOLOGYの公開コード、Microsoft設定、本人のOneDriveへはこの更新から書き込みません。

## OneDriveの接続操作

上部の共通バーに「未接続」「確認中」「接続中」「接続済み」「再接続が必要」を表示します。「OneDriveに接続」から直接Microsoftへ接続でき、アカウント選択を毎回強制しません。「接続設定」からアカウント変更とサインアウトを選べます。通信・アクセス許可の問題は未接続と区別します。旧画面の接続・アカウント変更・サインアウトのボタンは削除し、共通の操作だけを表示します。

「接続済み」は認証・接続の状態です。保存・同期の完了は各アプリの保存表示で確認してください。Safariの「履歴とWebサイトデータを消去」後は再接続が必要です。既存の保存領域・OneDriveのファイル形式・AppFolder権限を維持しています。

## PRACTICE内のCANVAS再生

各メニューの「CANVAS import」からCANVAS JSONを取り込むと「CANVAS 再生」が表示されます。作成中・保存した練習の両方で、使用した固定版の選手・ボール・線・コーン・文字を表示できます。連続再生、一時停止、次／前の動作・STEP、最初に戻る、STEP選択、速度変更、繰り返し、STEPメモ、移動線の表示切替、キーボード操作に対応します。CANVAS内の画像・動画素材は元のCANVASで確認してください。

閲覧コードは初回表示時に読み込み、コート背景はSTEP単位で保持します。動作中は1つの描画ループだけを使い、一時停止・閉じる・バックグラウンド移行時は停止します。作戦の表示・再生はクラウド通信や書き込みを行わず、アプリ本体の事前取得完了後はオフラインでも使えます。保存済みのJSON、既存のデータ形式、OneDrive同期は変更しません。

CANVASの通常書き出し（選手未関連のパス線に `playerId: null` を含む形式）と、旧形式の任意点列・表示配列のnullに対応します。実際のCANVAS書き出しを回帰検査に使用し、保存済みの原文は変更しません。

CANVAS importでOneDriveの一覧や選択したファイルを取得している間は「読み込み中」を表示し、重複した読込を止めます。取得後はCANVASの保存先と同じフォルダ階層、パンくず、上の階層への移動で探せます。検索は全フォルダのファイル名・フォルダ名を対象とし、英字の大小・全角半角・ひらがな／カタカナを区別しません。同名の検索結果には保存先を表示します。

フォルダ移動と検索は取得済みのメタデータだけを使い、追加のOneDrive通信は行いません。一覧はメモリー内だけに保持し、ファイル本文は選択時に取得します。失敗した場合はダイアログ内に理由を表示して再試行でき、閉じた後やアカウントが変わった後の応答を別のメニューへ反映しません。認証設定、保存形式、既存の列挙上限、元のCANVASファイルは変更しません。`node tools/canvas-import.browser.mjs`（生成したapp内）でChromium／WebKitの回帰検査を実行します。

## 公開版番号

現在の公開版は **1.3.8** です。以後、公開する変更ごとに `production/release.json` の版番号を必ず増やします。最終生成処理で画面・config・診断・Service Worker・検証記録を同じ番号に揃えます。PRとmainへの反映時は比較元より版番号が増えていなければ公開検査を失敗にします。同じ成果物の再検証・再公開は番号を増やす必要がありません。保存データや認証設定の識別子は維持します。

## 練習メニューの確認と再利用

詳細画面は確認・CANVAS再生用です。「次の計画に追加」「CANVAS JSONを書出し」を外し、各メニューに完了チェックを付けました。チェックはページのメモリーだけに保持し、同じ固定版の再表示や同期・記録保存では保ち、再読み込み・アプリの再起動で消えます。端末保存、実績、振り返り、OneDrive、バックアップには含めません。

計画作成のメニュー追加に「過去のメニューから追加する」を置き、カテゴリー別表示・絞り込み・検索から選んで末尾へ追加できます。初期の未入力メニューだけは置き換え、それ以外の入力を保ちます。時間・関連用語・Variation・条件・CANVAS原文・参考資料・添付を固定版からコピーし、元の計画や実績を変更しません。競合・関連不足・アーカイブのメニューは既存の再利用規則に従って除外します。

## 関連用語の検索と複数選択

メニューの「用語を検索・複数選択」から、TERMINOLOGYの英語・日本語・略語・定義で検索できます。候補をチェックし、「選択した○語を反映」を押してください。検索を変えても選択は残り、選択済みの用語を個別または一括で外せます。「閉じる」やEscでは編集前の関連付けを保ちます。

選んだ用語のID・名称・定義を固定版として保存し、詳細表示、コピー、過去のメニューから追加、保存したメニュー構成、バックアップ、OneDrive同期で引き継ぎます。1メニュー100語までです。既存の関連用語なし・単一用語の保存形式を保ち、複数の場合だけ既存用語オブジェクトに追加の固定版を持たせます。OneDrive認証、保存領域、保存スキーマ番号は変更しません。

## 起動時の接続・同期の入口

上部の雲アイコンはアプリの読込前から表示します。起動中でも準備状況を確認でき、アプリの読込・端末保存の準備が失敗した場合は確認箇所と再読み込みを案内します。15秒以上かかる場合も処理が続いていることを表示します。ファイル取得の一時失敗だけはアプリ実行前に一度再試行し、認証・DB初期化・保存の再試行や自動再読み込みは行いません。入力中・保存中・添付の取込中は案内の再読み込みを止めます。正常起動後は既存の雲アイコンと接続・同期操作に切り替わり、入口を重複させません。

SafariでWebサイトデータへのアクセスを拒否された場合は設定確認を案内します。保存・認証領域や既存のService Workerを消して復旧する処理は含めません。JavaScriptが無効な場合も画面上部に設定案内を表示します。
