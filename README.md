# ZERO ONE PRACTICE — 公開検証版 0.3.2

既存のZERO ONE CANVAS・TERMINOLOGYを置き換えず、練習計画・実績・振り返りをつなぐ検証用アプリです。

公開先：<https://yuge-u.github.io/zero-one-practice-lab/>。公開できたかどうかはActionsのDeployジョブと、その後のHTTPS検査結果で確認します。

## 最初に試すこと

SafariまたはPCブラウザで開き、架空の練習を入力して「端末に保存」し、再読込後に「保存した練習」から確認してください。最初はゲスト領域です。ゲストの記録をMicrosoft接続時に自動移行・送信することはありません。

この版は実運用の唯一の記録先にしないでください。物理iPhone、ホーム画面版、機内モード、長時間ロック復帰、本人OneDriveとの同期は、別途受入確認が必要です。氏名・健康情報などの実データは受入完了まで入力しないでください。

## 保存とプライバシー

端末内の保存はブラウザSQLite／OPFSです。OneDriveへ接続する場合は本人のMicrosoftアカウントを使い、アプリ専用領域の `ZERO_ONE_PRACTICE_LAB_V02` を使用します。初回作成にはアプリ内で明示確認が必要です。

GitHubはアプリの静的コードを配信します。練習・振り返りの本文をこのリポジトリへ保存する機能はありません。既存CANVAS・TERMINOLOGYの書込み処理を本アプリが置き換えることもありません。公開ホスト自体のアクセスログ等まで存在しないという意味ではありません。

## Microsoftの設定

実際に公開URLを開けることを確認した後、既存Microsoftアプリ登録 `b75b499d-2b47-42ed-9e10-41cd76dbc6c5` のSPAリダイレクトURIに `https://yuge-u.github.io/zero-one-practice-lab/` を追加します。既存URIは消しません。クライアントシークレットを作る必要はありません。パスワードや認証トークンをIssue・チャットへ貼り付けないでください。

## 再現可能な公開処理

初回公開は、既存の検証用ソースを `release-lock.json` のコミットへ固定して取得し、同じ準備処理で静的ファイルを構成します。参照元は `Yuge-U/basketball-tactics-board` の検証コードです。元リポジトリへ書き込む権限や処理はありません。

28ファイルを検証済み配布版のSHA-256と完全照合し、公開パスを模したWebKit／Chromium試験が通った場合だけPagesへ配信します。公開後は実HTTPS上で配信バイト列・起動・保存・再読込・390px表示等を改めて検査します。元ソースの可変ブランチ先頭へ自動追随しません。

CIは合成データと空の検証プロファイルだけを使用します。Microsoftサインインや本人OneDriveへのアクセスは行いません。試験ログ・スクリーンショットはActionsのArtifactsへ保存し、静的サイトには含めません。
